CODE MINI 1000T モード
・卓側：MIDI Setting（取説 8.2.3）で MIDI mode を Slave Mode にしてください。
・卓の MIDI Channel は 0〜15 表記です（卓の 0 ＝ このアプリの ch 1）。
・フェーダー n は「9n pp ll」（pp＝プレイバック番号 0〜14、ll＝レベル 0〜127）で、今表示中のページのプレイバック1〜15を動かします。Fixed のプレイバックは MIDI では動きません。
・PG −/＋ は「Bn (ページ−1) 00」でページを切り替えます（1〜40）。
・FLASH は押している間レベル 127 を送り、離すとフェーダーの値に戻します。SWOP は CODE では使えません。

・フェーダーはCC（値0〜127）、FLASH / SWOPはノート（押す＝Note On 127、離す＝Note Off）を送ります。
・Quartz側：System → Triggers で Mapping を作り、Item（Set Level / Flash / Swop など）を選んで Learn のまま各操作子を動かせば割り当てられます。
・卓からの戻りはないため、卓側でレベルを触った後は RESEND で今の値を送り直してください。
・名前はフェーダー上部の名前欄をダブルタップで変更できます。
